# 0009. Maps provider and fallback

Status: Proposed

## Context

Routes, ETA, place search and walking directions are needed (P1-TRIP).

## Decision

Google Maps Platform (Routes, Places) through a `maps` adapter in an Edge Function, so keys stay server-side and responses for common routes are cached. OpenStreetMap-based tiles are the fallback for map display.

## Options considered

Mapbox; OpenStreetMap only (weaker traffic data).

## Consequences

Budget alarms and API key restrictions on day one.
